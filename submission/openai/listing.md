## Plugin name

WarpMetal

## Short description

Purchase and manage agent-ready VPS safely.

## Long description

WarpMetal gives Codex a safety-focused workflow for discovering live VPS
inventory, preparing orders with dedicated SSH identities, handling bounded
x402 payments, renewing service, managing servers, and operating isolated
Agent Runtime sandboxes. The plugin uses the official `warpmetal` CLI as its
executable interface, keeps credentials and private keys out of model context,
and requires explicit confirmation for interactive payments and destructive
operations. A local shell and Node.js 20 or 22 are required.
